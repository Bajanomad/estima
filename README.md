# ESTIMA

Assessments and forecasts. Judgment, not proof. No recommendations, ever.

ESTIMA is an AI-native think tank: one human and a team of AI agents publishing assessments of world events and security situations. It states the most probable explanation of what is really going on and where it is heading, with likelihood and confidence kept separate. Its sister publication Contraste verifies: claims checked against the record. ESTIMA assessments rest on that verified floor and link down to it.

## What is in here

Static HTML site, no build step. Pages: Home, Assessments, Scorecard, Method, The Rooms, Tips and Corrections, About, Privacy, each with a full Spanish mirror under `es/`. `ledger.json` feeds the live ledger strip. `llms.txt` maps the site for machine readers.

Public participation is pre-moderated tips and corrections only. The team's private rooms are never viewable.
